# ondam-liff-test

온담이 ☀️ 카드의 **[📍 지금 있는 곳 날씨]** 버튼이 여는 LINE 안 웹 화면(LIFF).
4단계 설계 8절의 실험으로 시작해(위치 읽기·대화방에 위치 메시지 보내기 확인), 지금은 실제 페이지로 쓴다.

- 열리면 휴대폰 위치를 읽어 대화방에 위치 메시지 하나(제목 「📍 지금 계신 곳」)로 보내고 바로 닫는다.
  온담이는 이 제목인 위치만 날씨용으로 받는다 — 제목을 바꾸지 않는다.
- 위치를 못 읽으면 보내지 않고 「위치를 못 읽었어요. 다시 눌러 주세요」와 [다시] 버튼.
- 비밀값 없음. LIFF ID 는 공개 값(주소의 `?id=` 로도 받는다).
- 위치는 이 페이지가 저장하지 않고 LINE 대화방으로만 보낸다.
